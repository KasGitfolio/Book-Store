# Book-Store
Web based book store that was created as part of a university project.
This book store features a home page where books are displayed with their icons, descriptions and pay button. When purchasing the book, a payment form is displayed, the card details are sent over the server with an API using a post request, depending on the status code received, either the user has to re enter their details or a success page is followed. This store was created in MS Visual Code using javascript, HTML and CSS.
